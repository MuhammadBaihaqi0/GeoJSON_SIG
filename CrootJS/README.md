# Peta Rute GoRide — CrootJS

Website statis untuk menampilkan garis lurus dari Alun-Alun Bandung (Jalan Asia Afrika) menuju Universitas Logistik dan Bisnis Internasional (Jl. Sariasih No. 54, Bandung) pada peta Leaflet. Estimasi waktu berkendara dihitung terpisah mengikuti jalan; garis pada peta tetap lurus.

## Isi folder
- `index.html` — struktur halaman
- `css/style.css` — tampilan halaman
- `js/main.js` — interaksi dan peta Leaflet
- `js/config.js` — data GeoJSON
- `data.geojson` — data yang diberikan, disalin sebagai GeoJSON

## Menjalankan
Buka `index.html` di browser atau jalankan melalui server lokal seperti VS Code Live Server. Peta dasar dan estimasi waktu memerlukan koneksi internet.

## Teknologi
HTML, CSS, JavaScript, Leaflet, OSRM untuk estimasi waktu berkendara, dan peta dasar Esri.
